# Go Bear to Farm! 🐻🚗🌱

**生産者と援農者が、つながるきっかけをつくる。**
🐻 畑に行ってみたい人を、🚗 仲間の相乗りで、🌱 畑へ。

Built with Claude: Japan 2026 に提出した操作デモです。登場する人・農園・駅・データはすべて架空で、複数の経験から着想した架空の場面です。

- **デモ動画**（2分8秒・日本語字幕）：[video/go-bear-demo.mp4](video/go-bear-demo.mp4)
- **デモ（ブラウザで操作・ログイン不要）**：https://claude.ai/artifact/KmoctpZL527FpJKSweqEu8
- **デモのソース**：[go-bear.html](go-bear.html)（1ファイル。ダウンロードしてブラウザで開けば動きます。外部への通信はありません）

## 誰のどんな課題か

- **自然栽培の生産者**：作業の予定が読みづらく、「来て」と声をかけるタイミングに迷うこともある。
- **援農者（畑に行ってみたい人）**：受け入れの状況が見えず、迷惑にならないか気になることもある。車がなく、駅から畑まで遠いこともある。
- **畑に通い慣れた仲間**：知っている人の車なら一緒に行きやすい。その車には空いた席がある。

このデモは、生産者の「来てほしい」と援農者の「行きたい」を見えるようにし、仲間の相乗りでつながるきっかけをつくります。

## 3つの視点（画面上部で切り替え・認証ではありません）

| 視点 | できること |
|---|---|
| 🐻 援農者（車に相乗りする人）：P-01 | ①畑を選ぶ（生産者のひとこと・募集人数・受け入れの状態）→ ②行き方（駅から畑への概念図、運転者ごとの乗れる席、集合場所の条件を受け入れて合意を記録）→ ③参加希望を伝える → ④畑に着く時間・出る時間を伝え、当日までの状態を見る |
| 🚗 援農者（車を運転する人）：D-01 | 自分の車の便ごとの空席、乗りたい人、合意を記録した人を見る。集合場所の条件を選ぶ |
| 🌱 生産者 | 一緒にやりたい作業と募集人数を書き込む。受け入れを選ぶ（相談中・受け入れ合意・延期・見送り）。誰がいつ来て、いつ帰るかを確認する |

画面下の「調整のための詳細」には、援農グループと農園の関係図と、すべての便の需給（便ごとの乗りたい人数と空席）があります。

## 試し方（約2分）

1. 視点を「🌱 生産者」にし、作業（例：草取り。人手があると助かります）と募集人数を入れて「援農者の画面に反映する」を押す。
2. 視点を「🐻 援農者（車に相乗りする人）」にし、①でこもれび農園を選ぶ。
3. ②で運転者 D-01 の条件（里山駅集合）を受け入れて合意を記録する。
4. ③で「参加希望」、④で畑に着く・出る時間を伝える。
5. 視点を「🚗 運転する人」にし、自分の便に P-01 が表示されることを確かめる。
6. 視点を「🌱 生産者」に戻し、誰がいつ来て、いつ帰るかを確認して、受け入れを「延期」にする。
7. 「🐻 援農者」に戻り、受け入れの延期と移動の記録が別々に表示されることを確かめる。

## 決まりごと

- 集合場所は運転する人が条件として出し、乗る人がそれを受け入れて合意を記録します。この合意は乗る人の側の記録で、運転者本人の承認ではありません。
- 合意を記録しても、席の不足は自動では解消されません。別の便の余裕で不足を相殺しません。
- 同じ日に、2つの畑の予定（参加希望・時間の申告）は入れられません。
- 受け入れと移動の記録は別々です。延期しても、移動の記録は自動では取り消されません。実際の参加や移動は、関係者どうしで確認します。
- 「二日前まで」は連絡の目安です。遅れた連絡も自動では断りません。

## このデモでできないこと

- 検索や、新しい参加・相乗りの申し込み（申し込みは事前に用意した架空データです）
- 運転者がアプリで同乗を承認すること
- 予約・配車、保存・外部送信・通知、延期したときの自動取り消し・再調整
- 実際の位置・経路・所要時間の表示（地図は仮の配置の概念図です）
- 氏名・住所・電話番号の入力（入力欄はありません）

操作の結果はブラウザの画面の中だけに残り、再読み込みすると元に戻ります。

## テスト

```sh
npm install
npx playwright install chromium
node test-gobear.cjs
```

`test-gobear.cjs`（23項目）では、次のことを確認しています。
- 便ごとの需給の計算、相殺しないこと、重複して数えないこと
- 3つの視点の操作範囲
- 集合場所の条件の受け入れ、同じ日の二重予約の防止
- 生産者の入力が反映されること、受け入れと移動の記録が別であること
- スマートフォン幅での表示、外部への通信がないこと

## 名称について

公開している名前（農園・駅・団体・人物）はすべて架空です。開発用に名前を差し替える `scripts/make-local.cjs` がありますが、対応表（`*.local.json`）と生成物（`*.local.html`）は git の管理外で、公開していません。`scripts/check-public.cjs` で、公開ファイルに差し替え後の名前が含まれていないことを確認できます。
